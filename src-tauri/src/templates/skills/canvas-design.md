# 海报视觉设计 Canvas Design

做海报 / 封面 / 视觉稿时用。目标是**美术馆级静态视觉**，不是"AI 味卡通图"。两段式：哲学先行，再落画布。源自 Anthropic 官方 canvas-design。

## Phase 1 · 设计哲学（先写字再动手）
- 为这次委托原创命名一个美学流派（1-2 词），写一段哲学宣言，从五个维度展开：空间与形态 / 色彩与材质 / 尺度与节奏 / 构图与平衡 / 视觉层级。
- 配色、字体、构图的每个决定都必须能追溯回这段哲学，不许"顺手好看"。

## Phase 2 · 概念演绎
- 从需求里挖隐性引用：主题背后的行业、器物、年代、质感，像爵士乐里的引用——懂的人能看出来，不懂的人只觉得对味。选色扎根主题本身的材质与语汇，不用万金油配色。

## Phase 3 · 画布表达
- 用自包含 HTML + CSS 精确排版（固定画布尺寸），再截图出 PNG；印刷需求出 PDF。
- 构图手法：重复图案、系统性肌理、大胆的尺度对比、非对称平衡。
- 字体排印是作品的一部分：选有性格的字体搭配，标题可作图形元素处理。

## 红线
- **90% 视觉 10% 文字**：文字只留必要信息，海报不是说明书。
- 任何元素不许意外重叠，每个元素要有呼吸空间。
- 禁止：卡通贴纸感、emoji 堆砌、紫蓝渐变 + 居中卡片的 AI 模板、模仿具体在世艺术家。
- 交付前自审一轮：截图放大看细节，删掉一个最多余的元素再交。
