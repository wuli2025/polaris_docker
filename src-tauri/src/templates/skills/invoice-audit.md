# 发票报销批量整理

把一堆散落的发票 / 收据（PDF、图片、截图）批量提取、查重、重命名、归档，出可对账的台账。报销季神器。源自高星合集的 invoice-organizer + 官方 pdf 提取管线。

## 流程
1. **清点**：扫目录识别 pdf/jpg/png，先报总数和日期范围让用户确认范围没扫错。
2. **逐份提取**：PDF 文本层用 `pdfplumber`（保版面提字段和表格）；扫描件 / 图片转图后 OCR。中国增值税发票认这些字段：发票代码、发票号码、开票日期、销售方名称、价税合计、税额、品目；国外票认 Invoice No. / Invoice Date / Total / Vendor。
3. **兜底**：提取失败的用文件名线索 + 文件修改时间猜，**并标记「待人工复核」**，不许编数。
4. **查重**：同发票号码 = 重复报销风险，必须单独列出；同内容不同文件比 hash，留高质量版。
5. **重命名归档**：`YYYY-MM-DD 销售方 - 金额 - 品目.ext`（去特殊字符，日期可排序）；归档目录按用户选的策略：按供应商 / 按费用类别（差旅 / 办公 / 软件…）/ 按年月 / 混合。
6. **双产出**：
   - CSV/Excel 台账：日期、销售方、发票号、品目、金额、税额、类别、文件路径、复核标记。
   - 汇总报告：总笔数、日期范围、总金额、按类别小计、重复 / 待复核清单。

## 红线
- 金额、税额必须来自票面原文，提不出来就标复核，**绝不推算补齐**。
- 多页发票合并成一个 PDF 并在台账注明页数。
- 原始文件只复制 / 重命名副本，不删除不覆盖原件。
- 涉及真伪查验（税局验真）只提示用户官方渠道，不代查。
