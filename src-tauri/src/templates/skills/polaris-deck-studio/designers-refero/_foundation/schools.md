# 设计流派（schools.md）

> 把约 285 个一线产品官网公开设计系统的**共性气质**归纳为 11 个流派、24 位设计师。流派定「大方向 + 主打动效母题」，设计师定「具体配方与性格」。
> 动效母题引用 `motion-library.md` 的 `[Mn]`；美学公理引用 `aesthetics.md` 的 `[An]`；工艺纪律引用 `taste.md` 的 `[Tn]`。
> 版本 v2.1（2026-07-08）。v1.0 的 I–VIII 派按「视觉气质」归纳；v2.0 增 IX–XII 四派，改按「动效母题」定义。v2.1 裁撤 12 位设计师（整个流派 IX 及各派部分成员），名额暂不补齐。

## 流派 I · 印刷静默派（Print-Silence）
**信条**：浏览器即印刷品。运动会破坏印刷的沉思感——所以几乎不动。
**气质**：报纸大开本 / 图录 / 编辑跨页。无彩底 + 墨黑字 + 唯一信号色。
**主打动效**：M8 巨字尺度 · M9 硬色场翻页 · M10 图像自身反馈 · M2 无阴影托层。手感=有机长时。
**设计师**：`inkwell-press`（墨库主编）· `broadsheet-grid`（大报网格师）

## 流派 II · 策展留白派（Gallery-Vitrine）
**信条**：把内容当展品，界面是展柜，留白是布光。
**气质**：博物馆展陈 / 画廊墙 / 产品崇敬。大留白、微旋错落、居家安静。
**主打动效**：M2 无阴影托层 · M10 图像反馈 · M12 微旋 z 叠 · M7 滚动揭示。手感=有机长时。
**设计师**：`plinth-curator`（展台策展人）· `vitrine-photo`（橱窗摄影师）· `salon-hang`（沙龙错挂师）

## 流派 III · 字体纪念碑派（Typographic Monument）
**信条**：字大到成为建筑，就不需要别的装饰。
**气质**：粗野编辑 / 朋克海报 / 瑞士新怪诞。超大 slab、负字距、高对比。
**主打动效**：M8 巨字尺度 · M11 方向性微位移 · M13 渐变裁切扫过 · M9 硬切。手感=机械短促。
**设计师**：`slab-monument`（字碑工头）· `swiss-mason`（瑞士砌字匠）· `punk-broadside`（朋克海报手）

## 流派 IV · 深空控制台派（Deep-Space Console）
**信条**：像一台精密仪器，冷静、可信、每个像素都在报数。
**气质**：任务控制室 / 开发者终端 / 实验室仪表 / 深空观测台。极深底 + 等宽 + 单点信号色。
**主打动效**：M5 签名艺术品（粒子星座/网络图脉动）· M15 数字滚动 · M14 描边环转 · M1 稀缺色。手感=机械短促。
**设计师**：`mission-control`（控制室台长）· `terminal-mono`（等宽终端师）

## 流派 V · 电影暗房派（Cinematic Darkroom）
**信条**：灯先暗下来，重要的东西才显影。
**气质**：影院黑箱 / 暗房显影 / 静奢虚空 / 时装暗调。纯黑虚空 + 一束光 + 慢揭示。
**主打动效**：M3 慢入场（blur→focus 显影）· M2 无阴影托层 · M10 图像反馈 · M6 跑马灯标点。手感=有机长时。
**设计师**：`darkroom-reveal`（暗房显影师）

## 流派 VI · 氛围辉光派（Ambient Aurora）
**信条**：颜色不用画出来，晕出来；深度不用堆出来，透出来。
**气质**：星云辉光 / 极光渐变 / 毛玻璃分层 / 硅谷 AI 官网。深底 + mix-blend 光球 + 磨砂。
**主打动效**：M5 星云漂移 · M13 渐变裁切扫过 · M7 粘性毛玻璃 · M2 无阴影托层。手感=有机长时。
**设计师**：`nebula-drift`（星云漂移师）· `glass-frost`（毛玻璃分层师）· `aurora-sweep`（极光扫描师）

## 流派 VII · 暖纸书卷派（Warm-Parchment）
**信条**：像一本印在暖纸上的研究专著，字是主角，一点陶土色只在动作处出现。
**气质**：羊皮纸编辑 / 科学期刊 / 文学刊物 / 安静奢华。暖奶油/羊皮纸底 + 衬线大字 + 单枚陶土/黛色强调。
**主打动效**：M1 稀缺色（陶土 accent 只在动作亮）· M2 无阴影托层 · M11 方向性微位移 · 极致克制。手感=有机长时。
**设计师**：`monograph-serif`（专著衬线师）· `parchment-lab`（暖纸实验室）· `quiet-luxury`（静奢管家）

## 流派 VIII · 触感像素派（Tactile & Pixel）
**信条**：把界面做得可以「摸」——软的、贴的、像素的。弹簧只留给角色。
**气质**：粘土软萌 / 贴纸孔版 zine / 街机霓虹线框 / CRT 荧光复古未来。触感反馈 + 实体隐喻。
**主打动效**：M4 弹簧（仅限品牌角色）· M6 跑马灯 · M11 方向性微位移 · M1 稀缺色（霓虹/荧光标点）。手感=机械短促（弹簧例外）。
**设计师**：`clay-tactile`（软陶触感师）· `sticker-riso`（贴纸孔版师）

# 进阶动效流派 X–XII（v2.0 · 以动效母题定义，汲取 reactbits / refero；原 IX 动力字体派已于 v2.1 裁撤）

> 前八派按视觉气质分；这几派按**动效母题**分——它们的性格不在配色而在「怎么动」。每派仍守「默认态是静、动效是配给」：新技法越强，越只在唯一焦点处放一次。

## 流派 X · 滚动编排派（Scroll Choreography）
**信条**：滚动不是翻页，是时间轴——内容随滚动被导演。
**气质**：叙事长页 / 产品故事 / 交互年报。滚动钉幕、视差地层、横向卷轴，节奏由滚动进度掌控。
**主打动效**：M23 钉幕缩放 · M24 视差地层 · M7 滚动揭示 · M12 分层 z 叠。手感=有机长时。铁律：优先 CSS scroll-timeline，绝不 JS 监听 scroll，`reduce-motion` 无损降级。
**设计师**：`pin-stagecraft`（钉幕舞台师）· `reel-horizon`（横向卷轴师）

## 流派 XI · 磁吸物理派（Magnetic Physics）
**信条**：界面会回应你的手——指针即引力，但引力只给唯一焦点。
**气质**：作品集 / 高端落地页 / 精品卡片墙。磁吸按钮、聚光便当、微倾斜光泽卡，克制而有「实体在手」感。
**主打动效**：M17 磁吸指针 · M18 聚光跟随 · M19 微倾斜光泽 · M2 无阴影托层。手感=有机长时（缓吸复位）。铁律：交互动效只落焦点件，触屏/`reduce-motion` 关闭。
**设计师**：`magnet-atelier`（磁吸工坊师）

## 流派 XII · 流体遮罩派（Fluid & Mask）
**信条**：转场不淡入，靠形变与遮罩「揭示」——液态、有机、有仪式感。
**气质**：创意品牌 / 时尚发布 / 潮流媒体。融球导航、遮罩揭幕、点阵光束场，是四派里最「绚」的一派，但仍守相邻色相与配给纪律。
**主打动效**：M26 融球流体 · M20 遮罩揭幕转场 · M27 点阵光束场 · M14 描边环转。手感=有机长时。
**设计师**：`gooey-fluidist`（融球流体师）· `mask-wipe-editor`（遮罩揭幕师）

## auto 路由（内容气质 → 流派）
- 深度报告 / 编辑长文 / 图录 → 印刷静默派 或 暖纸书卷派
- 作品集 / 产品陈列 / 摄影 → 策展留白派
- 品牌宣言 / 海报级冲击 / 创意提案 → 字体纪念碑派
- 开发者工具 / 数据产品 / 技术汇报 → 深空控制台派
- 高端发布 / 奢侈品 / 影院感 → 电影暗房派
- SaaS/AI 官网 / 想「干净高级晕开」→ 氛围辉光派
- 科学 / 研究 / 安静高端品牌 → 暖纸书卷派
- 消费品 / 亲子 / 游戏 / 年轻潮玩 → 触感像素派
- 大字标题冲击 / 发布会主视觉 / 文字即主角 → 字体纪念碑派（III）
- 叙事长页 / 交互年报 / 滚动故事线 → 滚动编排派（X）
- 作品集 / 高端落地页 / 精品卡片墙（要「界面回应手」的高级交互）→ 磁吸物理派（XI）
- 创意品牌 / 时尚发布 / 潮流媒体（要绚，但要有转场仪式感）→ 流体遮罩派（XII）

## 硬约束（所有 refero 系设计师之上）
0. **动效代码抄 `recipes.md` 配方改参数，不自己发明**——每个 R-Mn 都是定稿骨架（FINE/REDUCED 闸、IO 触发、transform/opacity 限定内建），执行模型只换颜色/时长/文案；交付前跑配方的「验收断言」。
1. 继承 `aesthetics.md` 12 公理 + `taste.md` 11 纪律 + 对比度铁律（深底浅字/浅底深字，小字尤甚，只用 token）。
2. 动效遵 `motion-library.md`：只动 transform/opacity、IntersectionObserver、自定义缓动、`prefers-reduced-motion` 收敛可读终值；一位设计师只选机械或有机一种手感到底。
3. **默认态是静**：动效是配给出来的，不是铺满的。一页动效预算见 motion-library 末条。
4. 每位设计师照自己的动效母题组合与禁忌清单办；产物首行写遥测锚点 `<!-- designer: <id> · school <罗马数字> · dials V/M/D · preflight n/n -->`。
5. **一屏一主题（篇幅铁律）**：页面按幕组织，一幕 = 一个主题 = 一个视口（`100dvh` 或 min-height 且不溢出）；一幕装不下就拆幕，绝不缩字硬塞、绝不让单幕撑长页面；各幕高度一致，长列表在界定容器内自滚；1280×800 / 1440×900 下逐幕验收「不拖动即可看全本幕主题」。
6. **高级感与去 AI 味**：禁紫青渐变 hero、玻璃卡片矩阵、emoji 图标列表这类模板腔；质感靠真排版、真留白与一处准确的签名动效，文案克制不堆砌。
