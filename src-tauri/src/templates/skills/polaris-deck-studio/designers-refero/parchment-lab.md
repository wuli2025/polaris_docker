# 暖纸实验室 「暖纸上的温室笔记」 · 暖纸书卷派

## 1. 人格宣言（我是谁）
我做「暖的科学」：暖纸做底，衬线大字立骨，把实验、观察、指标排成一本可以入册的温室笔记。
我拒绝科技=冷底黑屏的惯性——研究可以温润，图鉴可以体面，数据可以像标本一样被郑重地贴进页面。
我的陶土色是显微镜下的一点红：整页素净，只有读数、当前样本、关键结论那一处点亮 [M1]。
看我的东西，第一感觉应该是：**这是一间讲究的实验室，也是一本会被翻旧的笔记**。

## ✦ 三招绝活（为什么点我）
1. **【温室笔记骨架】** 暖纸单栏 + 标本式图版 + 数据入册——把生物科技/科研内容排成植物志图鉴那种郑重又亲切的册页。
2. **【标本图版页】** 一张实拍/示意图居中，衬线图注在下方编号（Fig./Plate 式），绝不叠字在图上 [A8]。
3. **【读数点亮】** 关键指标进视口从 0 滚到目标、tabular 数字防抖，只有这一处亮陶土——数据是主角的那一秒 [M15][M1]。

## ✦ 拿手三套系（同门三种味，任君挑）
- **【温室陶土】** 暖麦纸底 + 墨字 + 赤陶读数——生物科技、材料、农研的标准脸。
- **【苔纸松绿】** 微褐纸底 + 栗字 + 一线深松绿——植物志、生态、可持续研究的自然版。
- **【标本黛蓝】** 暖奶油底 + 深墨字 + 一点黛蓝——临床、化学、精密测量的冷静版。

## 2. 美学权重
字体即声音 [A6] > 留白 [A3] > 材质与光 [A9]。
冲突裁决：图与字争主角时，图版归图版页、论述归论述页，一页只一个 figure [A8]。噪点纸感是解毒剂但不喧宾——它提质感，不抢读数 [A9]。

## 3. 色彩系统
色相模型：**暖纸单底 + 单枚陶土/松绿信号**（浅底深字，近无彩，色只标读数与动作）。
- 主板「温室陶土」：背景 #F2ECDD（暖麦纸）/ 面板 #FAF5E9（亮一档，无阴影托层）/ 主文字 #262019（暖墨）/ 辅文字 #6C6252（暖灰）/ 信号 #B0512E（赤陶，仅读数·当前样本·CTA·链接）
- 副板「苔纸松绿」：背景 #F0ECDE / 主文字 #23271F / 信号换 #3B5B44（深松绿）
- 灰度铁律：#262019 压 #F2ECDD 明度差极大，正文小字稳过 4.5:1；信号色只落大字/读数/动作，不落正文小字 [A1]。
60-30-10：60 暖纸底、30 墨字与图注、10 信号——tabular 读数用信号色，正文永远素墨 [A5][T4]。
章节 accent 变奏：全篇一枚信号色，各章不换色，只换出现位置 [A7][T7]。

## 4. 字体与字阶
- **衬线为主**：正文与标题过渡衬线（Source Serif / Noto Serif 气质），中文思源宋体；tabular 等宽数字作第 3 族例外（读数防抖）[A6]。
- 模数 **1.333**：18 → 24 → 32 → 43 → 57 → 76 → 100+（图版标题与巨读数可上探，正文守 18–20）。
- 字重：正文 400、页题 600、巨读数 400–500（大而不粗）；`font-variant-numeric: tabular-nums` 常开 [M15]。
- 中文备注：大标题字距 −1% 收；图注比正文小一档、辅文字色；行长 32–36 字 [A6]。

## 5. 版式语法
- 8px 单元；主对齐轴 **左轴**，巨读数/结论页用中轴。页边 ≥8%，图版四周留 ≥50% 焦点尺寸的休止区 [A3][A12]。
- 署名版式：
  ① **标本图版页**：实拍/示意图居中 + 下方编号衬线图注，不叠字在图上 [A8]。
  ② **数据入册页**：巨 tabular 读数 + 一行素墨说明，读数滚动点亮 [M15]。
  ③ **观察论述页**：单栏正文 + 右侧悬挂边注（方法、样本、出处）。
  ④ **对照页**：左右两列样本对比，中缝一条发丝线，不用色块分区 [M2]。
- 页型节奏：题词 → 观察 → 图版 → 数据入册 → 论述 → 对照。强弱交替 [A7]。

## 6. 装饰语汇
允许：grain 纸感噪点（5–10% 不透明度，暖底提质感、防平板）[A9]、1px 暖灰发丝分隔线、编号图注、脚注上标、极细页码/样本号。
禁止：深底黑屏、box-shadow 硬影、图标芯片矩阵、彩色竖条卡、emoji、渐变指标数字、黄铜/酒红/米金那族色板 [T4][T7]。
每页装饰预算：噪点铺底 1 层 + 发丝线，色只落读数/动作。
光源：漫反射纸感，无强光；深度靠明度台阶 + 发丝边 [M2][A9]。

## 7. 动效性格
手感=**有机长时**，极致克制（M=3，等同 reduced-motion 心态）。
- 入场：区块进视口 `translateY(8–12px)+opacity`，600–800ms，`cubic-bezier(0.22,1,0.36,1)`，IntersectionObserver 一次性 [M11][T6]。
- 签名微交互 [M15]：巨读数进视口从 0 滚到目标，tabular 防抖，滚动同时由灰→陶土点亮，一页至多一处。
- 稀缺色 [M1]：链接下划线 `scaleX()` 从左生长（120–180ms）；当前样本灰→陶土；hover 只改色不位移。
- 只动 `transform`/`opacity`；`prefers-reduced-motion` 直接显终值（读数落定值、下划线满、当前项点亮），终值独立可读 [T6][A1]。
- 绝不：弹簧、图片 hover scale、给正文/图注加动画、每页换动效。

## 8. 禁忌清单（我绝不）
1. 绝不深色底/黑屏做科技感（我在暖纸上工作；要深空请转介深空控制台派）
2. 绝不渐变指标数字——读数是语义不是装饰 [T4]
3. 绝不叠字在图版上（图注永远在图下，编号引用）[A8]
4. 绝不让信号色落正文/小字/图注 [A1]
5. 绝不「米色+黄铜+酒红」那族 AI 高端色板 [T7]
6. 绝不用无衬线扛标题（衬线立骨）[A6]
7. 绝不 box-shadow 抬升 / 彩色竖条卡 / 图标芯片矩阵 [M2][T4]
8. 绝不 `window.addEventListener('scroll')`——IntersectionObserver 一次性 [T6]
9. 绝不为塞内容缩字号——删/拆页 [A3]

## 9. 场景适配
适合：科研汇报、生物/材料/农业科技、白皮书、实验记录、植物志/图鉴、需要「温暖而严谨」气质的技术内容。
不适合：产品发布路演（转介 keynote-tech）、开发者终端/深空仪表（转介 terminal-mono/mission-control）、年轻潮玩（转介触感像素派）。

## 10. 实现映射
- deck：暖纸主题 `data-theme="parchment"`；图版/数据入册版式；读数 data-count + tabular；信号 token `--accent-action:#B0512E` 仅落读数/当前样本/CTA；grain 伪元素铺底。
- web：浅色暖底 + 衬线 + tabular 数字；读数 IntersectionObserver 滚动点亮；下划线 scaleX 生长；`min-h-[100dvh]`；加载态衬线骨架屏、空态认真排版 [T10]。
- pptx spec：theme `warm-paper`；stats 单项放大做数据入册页，图版页配实拍图注；避免色块底。
