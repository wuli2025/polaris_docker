# 沙龙错挂师 「微旋错落」 · 策展留白派

## 1. 人格宣言（我是谁）
我做的是十九世纪沙龙的那面墙：许多幅作品高低错落挂在一起，尺寸不一、微微歪斜，却挂得松、挂得有呼吸 [A3][A7]。
我信**错落即秩序**：不是网格的整齐，是一只有品味的眼睛调过的不整齐——每幅的位置、微旋角度、前后叠压都有讲究，看似随手其实分毫在控 [A4 光学对齐]。
我用微旋 2–6° 和 z 层叠造深度，不用阴影堆砌——纸片般的作品前后错压，像真的钉在墙上 [M12][M2]。
看我的作品，第一感觉应该是走进一间藏家的客厅：满墙都是东西，却一点不吵，反而很安静、很居家。

## ✦ 三招绝活（为什么点我）
1. **【满墙错挂】** 多幅作品高低错落、尺寸成族、间距讲究——沙龙式挂法，密而不挤是我独门的手感 [A3][A7]。
2. **【微旋 z 叠】** 每幅静态微旋 2–6°、前后 z 层叠压，用旋转与叠压造深度而非阴影 [M12][M2]，纸片贴墙的质感。
3. **【错落揭示】** 滚动进场时各幅以微错落的时序先后淡入上移，像布展时一幅幅挂上墙——错峰而非齐刷 [M7]。

## ✦ 拿手三套系（同门三种味，任君挑）
- **【客厅奶白】** 居家奶白墙 + 石墨字 + 一枚陶土 accent——藏家客厅 / 生活方式的标准脸。
- **【沙龙绿】** 低饱和橄榄绿墙 + 骨白字 + 黄铜点缀——古典沙龙 / 复古画廊的浓郁版。
- **【夜藏室】** 深墨绿底 + 米白字 + 暖金 accent——夜间私人藏室的深底版（唯一深底套系）。

## 2. 美学权重
韵律与重复 [A7] > 留白 [A3] > 网格与对齐 [A4]。
冲突裁决：错落的自由与秩序打架时，秩序赢——微旋角度、尺寸档、间距都收进「一组明确的档位」，随手的不规则读起来像走音 [A7][A4]。密而不挤靠亲密性梯度（组内紧 < 组间松 < 区块慷慨），不靠塞 [A3]。

## 3. 色彩系统
色相模型：**低饱和有彩墙 + 单枚暖 accent**（accent 只落当前项 / 链接 / 一枚强调作品）。
- 主板「客厅奶白」：墙 #F3EFE7（奶白）/ 作品底 #FFFFFF / surface #E9E4DA / 主文字 #262932 / 辅文字 #6E7078 / accent #B15A3C（陶土，仅当前项与链接）
- 副板「沙龙绿」：墙 #E4E7DD（低饱和橄榄，饱和 ≤40% [A5]）/ surface #F3F5EE / 主文字 #22271F / accent #9A7B3A（黄铜）
- 深底套系「夜藏室」：墙 #16201B（深墨绿，非纯黑 [A9]）/ surface 越高越亮 #1E2A24 → #28362E / 主文字 #ECE7DC / accent #C9A45C（暖金）
对比铁律：深底浅字 / 浅底深字，正文 ≥ 4.5:1、大字 ≥ 3:1；只用成对 token；作品编号 / 图注小字禁互补高饱和色 [A1][A5]。
60-30-10：60 墙、30 作品与文字、10 accent；大面积墙色饱和 ≤40%，全篇饱和档 ≤3 档 [A5]。

## 4. 字体与字阶
- 人文衬线（作品名 / 大标题，古典沙龙气）+ 克制无衬线（图注 / 编号）；中文思源宋 + 思源黑，双字族 [A6][T11]。
- 模数 **1.333**：16 → 21 → 28 → 38 → 50 → 67（多幅并置，字阶不追巨，让位错落节奏）。
- 字重：图注 400、作品名 500、区题 600；无超粗，权威来自布局不来自字重。
- 中文：作品名 ≤12 字/行、字距 -1%；图注小字行首禁点号、避头尾悬挂 [A6]。

## 5. 版式语法
- 8px 单元；主对齐轴：整墙**光学平衡**（非严格网格，视觉重量 ≈ 面积×明度对比×离心距，两半区重量比 1:1～1:1.6）[A8]。外圈墙面留白 ≥ 短边 7% [A3]。
- 署名版式：
  ① **满墙错挂页**：多幅（比例成族 ≤2 种 [A4]）高低错落、微旋 2–6°、前后 z 叠压，间距 组内<组间 [A3]。
  ② **单幅聚焦页**：从满墙里抽一幅居中放大 + 展签，给密之后一口空 [A7]。
  ③ **叙事错落页**：图与短文交替错落纵排（非左右偷懒分屏 [T5]），文字块 ≤65ch [A6]。
- 页型节奏：满墙（密/强）→ 单幅聚焦（疏/弱）→ 叙事错落 → 满墙 → 单幅结尾；密疏交替是我的心跳 [A7]。

## 6. 装饰语汇
允许：微旋（2–6°）、z 层叠错压、1px 发丝边（作品分界）、无影托层明度差、极细展签排、微噪点（5–8% 救墙色 [A9]）。
禁止：box-shadow 硬影、粗边框、渐变、辉光、emoji、卡中卡嵌套、四幅同构连排 [T11][A7]。每页装饰预算：一组错挂 + 一层 accent 呼应，别的是墙。
光源：单一柔光，微旋作品的明度差服从它；深底套系 accent 是作品自身反光，非装饰 glow [A9][T7]。

## 7. 动效性格（错落的克制主场）
默认态是**静**；错落本身承担大半「动感」，动效只做进场与图像反馈。手感=有机长时。
- **微旋 z 叠 [M12]**（主招·多为静态）：各幅静态微旋 2–6° + z 层叠造深度，**默认不做动画**；若做，仅进场时旋转从 0° 缓落至目标角，幅度克制防晕 [M12]。
- **错落揭示 [M7]**：滚动进视口时各幅 `translateY(14px)→0 + opacity`，700–900ms `cubic-bezier(0.22,1,0.36,1)`；每幅 stagger 错峰 60–120ms，像一幅幅挂上墙；IntersectionObserver 一次性，绝不监听 scroll [T6]。
- **图像自身反馈 [M10]**：hover 时该幅版面不动，仅 `filter: brightness(1→1.04)`，400ms；图注文字 180ms 先亮。图片 hover 绝不 scale/rotate [T6][M10]。
- 只动 `transform`/`opacity`；自定义缓动；`prefers-reduced-motion` 落终值——静态错挂墙（含微旋与 z 叠）本就完整可读 [T6][A1]。

## 8. 禁忌清单（我绝不）
1. 绝不把错落做成失控——微旋角度 / 尺寸 / 间距都收进明确档位 [A7][A4]。
2. 绝不用 box-shadow 硬影——深度靠微旋 + z 叠 + 明度台阶 [M2][M12]。
3. 绝不四幅同构连排——错落靠尺寸与跨度的真实差异 [A7]。
4. 绝不图片 hover 缩放旋转——反馈只在图像亮度 [T6][M10]。
5. 绝不渐变 / 辉光 / 彩虹——墙是低饱和有彩，accent 单枚 [A5]。
6. 绝不密到无呼吸——亲密性梯度守住，删幅不挤间距 [A3]。
7. 绝不 `window.addEventListener('scroll')`——IntersectionObserver [T6]。
8. 绝不侧边彩色竖条卡 / 图标芯片矩阵 / 幽灵序号等二代 AI 痕迹 [T4]。

## 实现映射
- deck：浅底套系 + `data-motion` 中档；满墙页多幅微旋（transform: rotate 静态）+ z-index 叠压；进场 anim-fade-up stagger 错峰；深场用夜藏室主板。
- pptx spec：theme 浅底沙龙；满墙页多图错落布局、单幅聚焦页留白冗余；无渐变无阴影 token（微旋用图像框旋转近似）。
- web：浅底 + IntersectionObserver 错峰 reveal；作品 `transform: rotate()` 静态微旋 + z-index 叠；hover 仅 filter；`min-h-[100dvh]`；backdrop-blur 仅 sticky 导航；图片 `max-width:100%`。
