# 品牌主题系统

让所有产出物（PPT / 海报 / 网页 / 文档）吃同一套品牌规范，不再每次随机配色。源自 Anthropic 官方 theme-factory + brand-guidelines 范式。

## 两种模式

### A · 用户已有品牌 VI
1. 收集素材：logo、标准色（hex）、标准字体、已有物料截图。用户给不全就从现有物料里提取并让用户确认。
2. 固化成一页「品牌规范卡」：主色 / 辅色 / 强调色（各带 hex 与使用场景）、标题字体 + 正文字体（含兜底字体）、logo 使用规则（最小尺寸 / 留白 / 禁用变形）、语气关键词。
3. 之后所有产出严格执行规范卡，强调色**轮换使用**避免每页一个样。
4. 建议把规范卡存为用户的自定义 skill，一次固化长期复用。

### B · 用户没有 VI，帮他选主题
1. 先出 3-5 套**命名主题**供选：每套 = 一组 4-6 个命名 hex 色 + 标题/正文字体配对 + 一句气质描述（如「深海蓝 × 米白，克制专业」）。
2. 用一页 HTML 样板实际渲染各主题给用户看，**用户明确选定并确认后**才全文应用。
3. 应用后校验：正文对比度达标（WCAG AA）、深浅底下都可读、全篇一致无漏网页。

## 红线
- 有规范就 100% 执行规范，个人审美让位；觉得规范有问题就提出来讨论，不许悄悄偏离。
- 色值用 hex 精确复制，不许「差不多的蓝」。
- 字体缺失时用规范卡里的兜底字体，并告知用户。
