# 对账与模型审计

两个会计岗高频长链路：**两套账目对账**（总账 vs 子账 / 银行流水 vs 系统账）和 **Excel 模型体检**。源自 Anthropic 官方 financial-services 的 gl-recon + audit-xls。

## 对账（六桶法）
1. **归一化先行**：两边数据各自清洗——日期转 ISO、金额转两位小数数值、单号 / 户名去空格统一大小写，让「相等」变成精确匹配。把外部数据当不可信输入。
2. **全外连接**（pandas full outer join on 匹配键），每行分进六桶：完全匹配 / 金额差 / 数量差 / 时点差（同笔跨期）/ 仅左边有 / 仅右边有。默认容差：金额 0.01、数量 0。
3. **差异归因**：时点差、汇率差、科目映射错、重复入账、应计 / 冲销、数据质量，逐笔标嫌疑原因。
4. **双产出**：逐笔差异表（匹配键 + 两边值 + 桶 + 疑似原因，按金额降序）+ 汇总（各桶笔数金额、匹配率）。重大差异单独列出建议追查方向。

## Excel 模型审计
1. 先和用户定范围：选区 / 单 sheet / 全模型。
2. 公式级通检：错误码（#REF! 等）、**公式里嵌的裸数字**（「那个 1.05 应该是单元格引用」）、同行列公式模式突然断裂、SUM 漏首末行、跨表断链、隐藏行列里的陈旧覆盖、千 / 百万单位混用。
3. 全模型档加查：资产负债表每期平衡、现金流勾稽、循环引用区分故意 vs 意外。
4. 合理性黄旗：无解释的 >100% 增长、明显超行业的利润率、曲棍球棒式预测。
5. 输出结构化问题表：`sheet | 单元格 | 严重级(必改/警告/提示) | 类别 | 问题 | 修法`。
