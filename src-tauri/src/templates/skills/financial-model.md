# 财务建模（三表 + DCF）

给公司建财务三表模型 / DCF 估值时用。产出是**活的 Excel 模型**：改任何假设全表联动。源自 Anthropic 官方 financial-services 的投行级施工规范。

## 总纪律
- **分段确认制**：历史数据 → 收入预测 → 三表 → FCF/WACC → 估值 → 敏感性，每段完成先给用户看再往下建，不许一口气建到底。
- **公式铁律**：所有计算写成 Excel 公式（openpyxl 写入），禁止 Python 算好硬编码进格子。每个硬编码输入格当场加来源批注（来源 / 日期 / 出处），不许留 TODO。
- 配色规范：蓝字 = 用户可改输入，黑字 = 公式，绿字 = 跨 sheet 引用；关键假设黄底。数字：货币标单位（万 / 百万），负数用括号，零显示 "-"，百分比一位小数。

## 三表要点
- 顺序：历史数 → 利润表 → 资产负债表 → 现金流量表。全部驱动数引「假设」页：COGS = 收入 × COGS%，禁止散落硬编码。
- 滚动公式固化：留存收益 = 期初 + 净利 − 股利；固定资产 = 期初 + CapEx − 折旧；应收 = 收入 × DSO/365（DIO / DPO 同理）。
- **两条勾稽铁律**：每期 资产 − 负债 − 权益 = 0；现金流量表期末现金 = 资产负债表现金。建 Checks 行自动校验，不平不交付。
- 利息循环引用：开迭代计算（100 次 / 容差 0.001）或加断路器开关。

## DCF 要点
- FCF 顺序固化：EBIT → 减税 → NOPAT → 加回 D&A → 减 CapEx → 减 ΔNWC → 无杠杆 FCF。
- 营业费用按**收入**的百分比建（不按毛利）；三情景 Bear/Base/Bull，增速前高后低收敛到终值。
- WACC 用 CAPM，权重用**市值**不用账面值；期末价值 g 必须 < WACC，期末价值占 EV 超 75% 亮黄旗。
- 情景切换用假设页选择器 + INDEX 归集列，禁止到处散 IF。
- 敏感性表：5×5 双变量（WACC × 终值 g 等），中心格必须等于基准输出（自验证），**每格都是完整重算公式，禁止线性近似**。

## 交付闸
- 交付前重算校验（LibreOffice headless 或 Excel 打开重算），#REF! / #DIV/0! / #VALUE! / #N/A 清零；抽查 2-3 个公式和跨 sheet 引用。
