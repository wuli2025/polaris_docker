# 生成艺术 Algorithmic Art

用代码生成艺术：p5.js 动态视觉、粒子系统、噪声场、图案生成。适合装置感背景、动态封面、创意编码。源自 Anthropic 官方 algorithmic-art。

## 三段式流程
1. **算法哲学**：先用一段话定这件作品的生成逻辑美学——混沌与秩序的比例、生长规则、色彩系统从何而来。算法是媒介，不是炫技。
2. **概念演绎**：把主题翻译成算法语言：流场（flow field）、L-system、细胞自动机、Voronoi、噪声位移、递归分形——选一个主手法做深，别堆砌。
3. **代码实现**：交付**单个自包含 HTML**（p5.js 走 CDN 内联引入），打开即跑。

## 实现约定
- **可复现性铁律**：`randomSeed()` + `noiseSeed()` 双设，同 seed 必出同图（Art Blocks 模式）。
- 内置控件：seed 前进 / 后退 / 随机 / 输入跳转，PNG 下载按钮。
- 每个暴露的滑块参数必须源于算法的内在自由度（密度 / 湍流 / 色相漂移），不许为了「有 UI」硬加。
- 动画用 `requestAnimationFrame` 节奏，提供暂停；性能守住 60fps（粒子数敢设上限）。
- 配色作为算法的一部分设计（HSL 空间里系统性取色），不许 hardcode 七彩。

## 红线
- 纯 CSS/Canvas/p5.js，**禁 WebGL 重依赖**，保证任何机器打开即跑。
- 先让最简版本跑起来再加复杂度，每步保持可运行。
- 交付时附一句「怎么玩」：哪个参数改了会发生什么。
